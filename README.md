# Restaurant Management System

Minimal restaurant order management app with backend and frontend folders.

## Structure

- `magic_backend_node/` — Node.js backend
- `magic_frontend/` — HTML/CSS/JS frontend

## Run

1. Open `magic_backend_node/`
2. Install dependencies: `npm install`
3. Start server: `node server.js`

## Notes

- Frontend is static files served separately or by the backend.
- Backend uses `db.js` and `server.js`.
